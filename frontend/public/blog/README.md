## Generation and optimization

Generated with the built-in image_gen tool, then resized to 1200 x 800 and encoded as WebP at quality 80 with Sharp. Four new images total 511,486 bytes. Original generation files are not needed at runtime.

Each image used this common prompt, with the corresponding scene inserted:

> Use case: illustration-story. Asset: wide 3:2 solar blog editorial image. Create [scene]. Polished naturalistic editorial illustration with tactile detail, restrained navy and green palette, central subject safe for 16:10 and 16:9 crops. No logos, captions, watermarks or Accutek identifiers. This is conceptual editorial imagery, not a photograph of a real customer installation.
