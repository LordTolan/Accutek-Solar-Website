Only the approval-process, manufacturing and myths article image fields change. Article text, URLs, other image choices and layout stay intact. The myths image previously had identical file bytes to the rapid-shutdown image despite a different filename. The image regression test now hashes the bytes of every referenced local hero asset; remote image bytes remain outside the offline test.
